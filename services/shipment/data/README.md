# Справочник станций Казахстана

`stations_kz.csv` — железнодорожные станции и остановочные пункты Казахстана.

## Колонки

| Колонка | Что это |
|---|---|
| `id` | стабильный ID записи: `osm-` + тип объекта OSM (`n` точка, `w` линия, `r` отношение) + его ID |
| `esr` | 6-значный код ЕСР (единая сетевая разметка станций стран бывшего СССР); пусто, если не найден |
| `kind` | `station` — станция, `halt` — остановочный пункт |
| `name` | название, как оно подписано в OSM (на казахском или русском) |
| `name_ru`, `name_kk`, `name_en` | названия на русском, казахском, английском; пусто, если перевода нет |
| `lat`, `lon` | координаты (WGS 84) |

## Откуда данные

- Названия и координаты — [OpenStreetMap](https://www.openstreetmap.org/) через Overpass API.
- Коды ЕСР — тег OSM `esr:user`, а если его нет — реестр [osm.sbin.ru/esr](http://osm.sbin.ru/esr/) (`osm2esr.csv`).
- Метро и другой городской рельсовый транспорт исключены.

## Обновление

```bash
make stations
```

Скрипт — [tools/stations](../../../tools/stations/main.go). Он перезаписывает CSV свежими данными. Изменения видны в `git diff`.
